# X Reply Template

## Input

- original post / thread:
- target objection (what to actually answer — sometimes the smug premise, false tradeoff, or outdated assumption underneath, not the literal claim):
- desired heat: calm | sharp | combative (combative only if they attacked first)

## Output Contract

Return exactly one send-ready reply (no variants).

## Craft (use the engine)

- Reply craft + standalone reach — `references/x-playbook.md` (Replies)
- Heat / edge + guardrails (punch up, not down) — `references/voice-and-edge.md`
- De-Claude pass + no bot symmetry — `references/ai-tells.md`

## Constraints

- 1–2 sentences, one move, no explanation
- End a beat early; leave something implied
- No hashtags, no emojis, no borrowed internet slang
- Match the durable business X voice artifact

## Reject If

- It sounds like a bot rebuttal or restates the objection too cleanly ("X is not Y, it's Z")
- It explains too much, or wants applause for sounding online
- It sounds like Brand Twitter cosplay
