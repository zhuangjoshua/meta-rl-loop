# Autonomous SEO and GEO Operator

Own per-business search-visibility audits and bounded SEO/GEO improvements across current site
source, plus a canonical visibility report, with no paid data dependency by default.

## When to Use

- A product site needs improved search or AI-answer visibility through honest metadata, schema,
  internal linking, sitemap, robots, llms.txt, or a few bottom-of-funnel pages.
- The operator wants a small, reviewable pass grounded in existing product truth and source.
- Existing Search Console, Keyword Planner, OpenSEO, DataForSEO, or SERP evidence can sharpen
  prioritization without blocking the run.

## Do Not Use

- Off-page work needing real external action, including backlink outreach, buying links, or posting
  to social sites and forums.
- Fabricating keyword volumes, rankings, reviews, testimonials, integrations, prices, competitor
  claims, or “best” and “number one” claims.
- Claiming live ranking wins, deployment state, or publication without real evidence.
- Generating hundreds of programmatic pages or near-duplicate location pages.

## Method

1. Read current business truth, public copy, routes, templates, metadata, structured data, navigation,
   and prior visibility evidence.
2. If current demand data is already available, use it to prioritize. Otherwise infer candidate
   queries from product, category, audience, pain, and use cases, and label them inferred.
3. Audit crawlability, indexability, canonicalization, status behavior, metadata, headings, internal
   links, sitemap, robots directives, structured data, answer-ready passages, and conversion intent.
4. Select one to five high-confidence changes. Prefer fixes that improve both human comprehension and
   machine interpretation.
5. Implement only claims supported by the product and existing evidence. Preserve design and working
   application behavior.
6. Validate routes, links, metadata uniqueness, structured-data syntax, and generated discovery
   files with the deterministic checks included in this skill when applicable.
7. Request the declared publication capability and produce the visibility report with observations,
   changes, evidence, inferred targets, validation results, and blockers.

## Prioritization

Rank work by expected impact, confidence, and effort:

1. indexing or canonical failures that hide real pages;
2. missing or misleading titles, descriptions, headings, and structured data;
3. weak internal discovery of important commercial pages;
4. answer-first passages, definitions, and entity clarity for AI citation;
5. a small number of genuinely useful bottom-of-funnel pages.

## Verification

- Each change maps to a diagnosed issue and uses only truthful business claims.
- Metadata and canonical targets are unique and route-correct.
- Structured data parses and matches visible content.
- Internal links resolve; sitemap and robots rules do not contradict intended indexability.
- Measured and inferred demand evidence are clearly distinguished.
- Publication and ranking state are reported only from observed evidence.

Use [references/seo-checklist.md](references/seo-checklist.md) for the detailed audit checklist.
Deterministic validators supplied by runtime policy may check metadata, routes, internal links, and
structured data; they do not prove indexing or rankings.
