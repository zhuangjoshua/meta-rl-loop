# Claude Design Superhuman

Layer this beneath `taste-frontend` and `claude-design` when the product should feel fast, premium,
and highly focused. Taste adapts this vocabulary to the brief; do not copy it verbatim.

## When To Use

- productivity apps
- email/communication tools
- focus tools
- premium operator software

## Visual Direction

- premium restraint
- dramatic hero moments
- clean white body surfaces
- fast, confident, minimal chrome

## Typography

- compressed powerful headings
- airy readable body text
- confident but understated UI labels

## Color and Tokens

- charcoal and white base
- one lavender/purple accent
- warm cream CTAs where appropriate

## Components

- minimal borders
- clean product screenshots or app panels
- restrained radii

## Hard Rules

- no clutter
- no rainbow palette
- no heavy enterprise chrome
- no childish whimsy

- `DESIGN.md`
- `tokens.css`
