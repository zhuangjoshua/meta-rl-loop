# Design Taste Frontend

Create marketing-facing interfaces that feel authored for their audience instead of assembled from
generic patterns. Every rule is contextual: read the brief first, then select the design language
that serves it.

## Design Read

Before editing, state one sentence: “Reading this as: [page kind] for [audience], with a [vibe]
language, leaning toward [appropriate design-system family].” Infer it from:

- page kind and conversion goal;
- the audience's expectations and trust requirements;
- the user's adjectives, references, and competitor set;
- existing logo, typography, color, photography, and interaction language;
- accessibility, regulatory, performance, and content constraints.

Do not default to the same fonts, dark gradient, glass cards, centered hero, or rounded tile grid for
unrelated businesses.

## Method

1. Read the brief and existing surface. Separate facts from assumptions.
2. Choose one visual thesis and define typography, color, spacing, radius, border, shadow, imagery,
   and motion rules as a coherent system.
3. Establish information architecture around the audience's decision sequence, not a stock section
   checklist.
4. Implement the strongest first viewport, then build the remaining story with deliberate rhythm and
   varied composition.
5. Use real copy and assets. Generate imagery only when it has a specific page role.
6. Add responsive behavior, accessible interaction states, reduced-motion handling, and performance
   safeguards.
7. Run the preflight and revise anything that still looks templated or unsupported.

## Non-Negotiables

- Respect an established brand and approved design contract on redesign work.
- Use semantic structure, visible focus, sufficient contrast, and keyboard-reachable controls.
- Keep decorative motion subordinate to comprehension and conversion.
- Do not fabricate testimonials, metrics, integrations, customers, awards, or product behavior.
- Do not use a design system merely because it is fashionable; match the audience and context.

## Verification

- The interface has a clear visual thesis that can be described without naming a trendy effect.
- Hierarchy, spacing, and responsive behavior hold at narrow and wide viewports.
- Primary actions and all interactive states are usable by keyboard and with reduced motion.
- Every prominent claim and visual is grounded in supplied evidence.
- The result passes the anti-slop preflight in
  [references/preflight.md](references/preflight.md).
