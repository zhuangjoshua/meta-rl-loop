# Claude Design OpenAI

Pair this with `claude-design` when the product should feel calm, serious, restrained, and trustworthy.

## When To Use

- AI tools
- analysis products
- serious prosumer software
- productivity surfaces
- research/publication-adjacent products

## Visual Direction

- near-monochrome
- generous whitespace
- quiet confidence
- editorial restraint instead of hype

## Typography

- restrained sans body with occasional editorial serif display moments
- modest weights
- hierarchy from spacing and scale, not loud decoration

## Color and Tokens

- white or mist backgrounds
- deep ink text
- one teal accent used sparingly
- hairline borders instead of heavy chrome

## Components

- soft but not cartoonishly rounded controls
- clean cards
- restrained shadows
- quiet pills and metadata

## Hard Rules

- no loud gradients
- no multi-accent palette
- no noisy marketing chrome
- no fake futurism
