# Claude Design Vibrant

Pair this with `claude-design` when the product should feel fun, energetic, and consumer-friendly without becoming chaotic.

## When To Use

- fun consumer SaaS
- creator tools
- colorful prosumer products
- lively brand surfaces

## Visual Direction

- colorful but clean
- playful display typography
- warm accents and strong hierarchy

## Typography

- expressive display type
- straightforward readable body type
- playful without becoming novelty-only

## Color and Tokens

- one purple primary
- one warm accent
- warm dark text on white surfaces

## Components

- clear cards and CTAs
- playful emphasis moments
- still usable, still structured

## Hard Rules

- no grayscale seriousness
- no generic startup blue-only palette
- no overloaded carnival UI

- `DESIGN.md`
