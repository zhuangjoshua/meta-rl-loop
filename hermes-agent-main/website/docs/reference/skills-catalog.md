# Bundled Skills Catalog

Takyon ships with a large built-in skill library copied into `~/.takyon/skills/` on install. Each skill below links to a dedicated page with its full definition, setup, and usage.

Takyon also syncs bundled skills on `takyon update`, but the sync manifest respects local deletions and user edits. If a skill listed here is missing from your profile's `~/.takyon/skills/` tree, it is still shipped with Takyon; restore it with `takyon skills reset <name> --restore`.

If a skill is missing from this list but present in the repo, the catalog is regenerated by `website/scripts/generate-skill-docs.py`.
