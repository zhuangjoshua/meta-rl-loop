# What V2 Did

V2 combined several systems into one Next.js repo:

- Takyon UI and onboarding.
- Older Argon/Fourmanifold dashboard routes.
- Company/task/event/document models.
- Workflow jobs and cron dispatcher.
- Hermes/Argon runtime integration.
- Direct LLM fallback paths.
- Product builder using Claude Agent SDK, Claude CLI, Vercel Sandbox branches, and Open Lovable branches.
- Generated app proxy, auth, checkout, Stripe webhooks, AI gateway, and project wallet.
- X OAuth/token refresh/posting.
- Meta/Atlas Seedance video generation and Meta campaign launch code.
- Outreach, leads, support, content, data, and operations workflows.

The product direction was useful. The implementation mixed too many eras and made it hard to know what really worked.
