# Prompt Registry

Prompts must be editable and auditable.

Each prompt has:
- prompt id
- title
- functionality
- default content
- active version
- change note
- last edited metadata

Each workflow run records the prompt version it used.

## Required Prompt Areas

- CEO wakeup
- initial foundation
- business plan
- market research
- workflow skill envelope
- product build
- product improve
- social draft
- find leads
- outreach copy
- cold outreach cycle
- content generation
- support reply
- activity review
- data report
- operations monitor
- UGC video
- Meta creative
- browser site policy
- generated app AI policy
