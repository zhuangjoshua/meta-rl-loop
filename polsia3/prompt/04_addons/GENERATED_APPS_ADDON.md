# Generated Apps Add-On

Owns:
- template registry
- generated app config
- generated app builds
- deployment adapter
- generated app proxy
- generated app auth/session
- generated app checkout
- generated app AI policy
- generated app runtime manifests

The add-on exposes workflows:
- build first generated app
- improve generated app
- deploy generated app
- smoke test generated app
- sync generated app health

Completion requires:
- source saved
- typecheck passed
- build passed
- deployment succeeded
- health check passed
