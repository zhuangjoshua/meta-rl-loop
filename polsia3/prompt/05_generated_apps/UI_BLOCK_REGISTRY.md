# UI Block Registry

Blocks should be modular and editable.

Initial homepage blocks:
- hero
- problem
- workflow preview
- outcomes
- pricing
- FAQ
- CTA

Initial app/product blocks:
- authenticated shell
- magic link gate
- entitlement state
- AI budget state
- product workflow panel
- result/output panel
- checkout CTA
- settings/account panel

Each block should have:
- component file
- schema/config type
- allowed variants
- required data
- empty/blocked states
- acceptance tests

Future user follow-up editing should modify config/block choices first before editing arbitrary code.
