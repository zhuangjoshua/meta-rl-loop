Takyon dashboard — redesign mockup

Visual of the proposed changes — no code touched. Open this file in a browser to compare with the live dashboard at /dashboard/companies/[id].

Markers

  • 1 · Website tile rebuilt. Tile header now matches every other tile: status chip (Live), last-updated time, real hostname inside the tile. Lane ribbon underneath shows the actual job lane statuses (website, seo, etc.) — same data the "In progress" tile already pulls from. Wireframe replaced with the real deployed site.
  • 2 · Product tile rebuilt. Same pattern. Customer count surfaced as the tile headline (currently buried in Performance footer tabs). Building state is a real skeleton + a moving progress bar tied to lane status, not a generic grey wireframe. Building chip when any lane is running.
  • 3 · Performance tile. Metric chips (customers / leads / posts) moved up next to the revenue number with mini values, instead of being centered at the bottom disconnected from the headline. Chart gets a baseline, last-point dot and dashed mid-grid.
  • 4 · X tile gets a header. Currently it's a "bare" tile with no label or status. The X post itself stays the same (already great); the addition is a header row so the tile reads like everything else on the board.
  • 5 · CTAs softened. "Publish post / Find leads / Find communities" buttons get a neutral fill #f6f9fc with a small green + mark, instead of bare green text on transparent. Reads as actionable rather than as another label.
  • 6 · Status chips desaturated. Live Building Idle use tinted backgrounds, freeing the full-saturation green for primary actions only.
  • 7 · Payments tile fleshed out. Used to be icon + 2 lines on an empty white card. Now shows MRR, last payment, and plan chips — exposes the same Stripe data already loaded into the model.

Overall changes

  • Hairline tile border rgba(15,23,42,.08) + 8px gap + soft box-shadow so tiles don't bleed into one mosaic.
  • Body text 12–13px (was 10–11px). Tile labels 12px dark, not 11px muted.
  • Empty wireframes replaced with skeletons that animate only while a lane is actually running.
  • Chart no longer renders fallback data when revenue is 0 — falls back to "No revenue yet" empty state (not shown here because the mock has revenue).
