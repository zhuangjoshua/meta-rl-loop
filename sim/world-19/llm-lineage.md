## Iteration 7 (policy v6 -> ?)
THESIS (pattern, cross-era, 5 observations; direction not causation): Verbatim
creative reuse fatigues — the same benefit prompt run in pageviews-broad five
eras straight decayed monotonically in CTR (2.52 -> 2.35 -> 1.27 -> 0.51 ->
0.63) and its CPL rose from $1.85 to $26.67, while freshly-written ads did not
show this slide. Direction: keep the winning angle assignments but write fresh
executions each batch. Confirming experiment (named, as the class requires):
next batch runs a newly written benefit-led brief in pageviews-broad; if it
recovers materially better CPL than the fatigued brief's recent eras, the
pattern holds; if it lands at the same depressed level, the cell itself has
cooled and the fatigue read is wrong. Middle doses at most for this class.

Doses (smallest -> boldest, capped at pattern-class boldness):
1. Add one sentence: creative may fatigue on reuse; writers may refresh winning briefs with new expressions of the same angle.
2. Default: each batch writes fresh copy for its assigned angles; reusing an identical prompt in consecutive batches is discouraged.
3. Rule: no ad prompt is reused verbatim in consecutive batches; each batch writes fresh executions; the pv-broad fresh-benefit comparison is run next batch.
4. Rule plus freshness ledger: every batch records new-vs-reused briefs, and reused-brief cells are read as fatigue-confounded evidence.
5. No creative execution runs more than two batches lifetime; angles persist, executions rotate; the confirming comparison is mandated next batch.
6. Fresh-creative discipline becomes a standing policy section: angle assignments persist, but every batch's ads must be newly written executions; verbatim reuse is barred until a matched test shows a reused brief holding its CPL; the pv-broad fresh-vs-fatigued comparison is the named confirming experiment.
